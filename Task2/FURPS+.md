| Код | Требования                                                                                                                                       | Комментарий |
|-----|--------------------------------------------------------------------------------------------------------------------------------------------------|-------------|
| F   | Функциональные (Functionality)                                                                                                                   |             |
| F1  | На сайте новый клиент видит список доступных депозитов с актуальными ставками                                                                    |             |
| F2  | Клиент может подать заявку на депозит, оставив свой номер телефона и Ф. И. О                                                                     |             |
| F3  | В интернет-банке клиент видит список доступных депозитов с актуальными ставками и персонализированные ставки лично для него.                     |             |
| F4  | Клиент может подать заявку в интернет банке на открытие депозита, указав счёт и сумму. Операцию необходимо будет подтвердить с помощью СМС-кода. |             |
| F5  | Функциональность ставок по депозитам, текущий процесс согласования ставки по заявке должен быть автоматизирован и реализован в АБС               |             |
| F6  | Менеджер бэк-офиса обрабатывает заявку на открытие депозита и подтверждает условия депозита в АБС                                                |             |
| F7  | Клиент получает СМС уведомление по факту открытия депозита                                                                                       |             |
|     |                                                                                                                                                  |             |
| U   | Удобство использования (Usability)                                                                                                               |             |
| U1  | Пользователи при работе должны видеть привычные цвета и брендированные элементы.                                                                 |             |
|     |                                                                                                                                                  |             |
| R   | Надёжность (Reliability)                                                                                                                         |             |
| R1  | Все сервисы (АБС, Интернет банк) должны работать 24/7 и быть доступны в 99,9% случаев                                                            |             |
| R2  | В случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку                                     |             |
|     |                                                                                                                                                  |             |
| P   | Производительность (Performance)                                                                                                                 |             |
| P1  | Отклик по всем операциям должен занимать миллисекунды                                                                                            |             |
| P2  | Возможность равномерного горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД                             |             |
|     |                                                                                                                                                  |             |
| S   | Поддерживаемость (Supportability)                                                                                                                |             |
|     |                                                                                                                                                  |             |
| +R  | + Ограничения (Restrictions)                                                                                                                     |             |
| +R1 | Данные с сайта необходимо защищать с помощью механизма шифрования трафика                                                                        |             |
| +R2 | В интернет-банке данные при передаче должны быть защищены с помощью механизма шифрования                                                         |             |
| +R3 | Функционал работы с СМС должен быть реализован силами команды разработки банка.                                                                  |             |
| +R4 | Для интернет банка необходимо использовать БД MS SQL, для АБС - Oracle.                                                                          |             |
| +R5 | Стек разработки интернет банк ASP.NET MVC 4.5 .NET Framework 4.5. Для других сервисов доступны Spring Boot, React.js                             |             |
| +R6 | Для реализации очередей использовать Kafka                                                                                                       |             |
| +R7 | Для процесса открытия депозитов использовать микросервисную архитектуру                                                                          |             |
| +R8 | АБС может масштабироваться только вертикально из-за своей базы данных                                                                            |             |
| +R9 | Необходимо отказаться от прямой работы интернет-банка с API АБС                                                                                  |             |
